# 乐转赠 (LeZhuanZeng)

一个非盈利赠物平台。让物质丰富的人通过赠与他人获得持久的快乐，让有需要的人免费获得物资。

与「断舍离」不同，乐转赠强调的是 **「转手赠与」** 这个动作本身带来的快乐，而非单纯减少物品后的轻松感。

## 核心理念

- **赠主**：把完好有价值但不再使用的物品发布到平台，乐于转赠
- **申领者**：提交真实使用需求，申请免费获取
- **匹配机制**：赠主自主根据申领内容选择最需要的申领者
- **物流方式**：赠主寄出到付包裹，邮费由申领者支付
- **反馈闭环**：申领者须提交使用照片 + 感谢信/视频

## 目标用户

- 赠主（有闲置物品愿意赠与）
- 真实需求的申领者（需要物资但希望免费获取）

## 平台形式

- **第一阶段**：Web 应用
- **后期**：微信小程序
