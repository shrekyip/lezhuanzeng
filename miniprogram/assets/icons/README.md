# 乐转赠小程序 TabBar 图标说明

## 图标规格
- 尺寸：81×81px（推荐）
- 格式：PNG（支持透明背景）
- 普通状态颜色：#999999（灰色）
- 选中状态颜色：#FF6B35（品牌橙色）

## 需要的图标文件
```
assets/icons/
  home.png          首页图标（普通）
  home-active.png   首页图标（选中）
  browse.png        浏览图标（普通）
  browse-active.png 浏览图标（选中）
  publish.png       发布图标（普通）
  publish-active.png 发布图标（选中）
  profile.png       我的图标（普通）
  profile-active.png 我的图标（选中）
```

## 临时方案
在正式图标准备好之前，可以：
1. 从 iconfont.cn 下载免费图标
2. 或使用微信开发者工具内置图标库
3. 或用下方 Python 脚本生成简单占位图标

## 图标建议风格
- 首页：房子 🏠
- 浏览：搜索/网格 🔍
- 发布：加号/礼物 🎁
- 我的：人物 👤
